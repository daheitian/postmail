# Compose H1 Title

## Plan

- Add a shared front-end helper that detects a leading non-empty H1 in TipTap JSON, extracts its text, and removes that block from the body.
- Wire note compose editing so an empty title can be filled from a leading H1 without changing backend/API behavior.
- Preserve user intent: only notes, only empty title, and never overwrite an explicit title.
- Add focused tests for extraction and compose editor behavior.

## Progress

- [x] Add helper
- [x] Wire compose editor
- [x] Add tests
- [x] Verify

## Results

- Added front-end-only leading H1 promotion for note compose.
- A leading non-empty H1 fills the existing title field and is removed from the body when the cursor leaves it, the editor blurs, or the submit payload is built.
- Explicit titles are not overwritten, and link/quote compose behavior is unchanged.
- Verified with `mise run check-tests` twice after implementation; final run passed typecheck, lint, library build, and 2609 Vitest tests.
