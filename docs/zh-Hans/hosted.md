# 使用 Jant 托管

如果你不想处理部署、升级、备份这些事，可以直接使用官方在 [jant.me](https://jant.me) 提供的托管服务。它和自托管运行的是同一份开源代码。

> 如果你希望完全自己掌控运行环境，请参阅 [使用 Cloudflare 部署](deployment.md) 或 [使用 Docker 部署](deployment-docker.md)。

## 价格

| 项目           | 价格      |
| -------------- | --------- |
| 第一个站点     | $10.46/年 |
| 每增加一个站点 | $5/年     |
| 包含的媒体存储 | 10 GB     |

按年结算，可随时取消。

## 包含的服务

- **完整的 Jant 功能**：Threads、Collections、GitHub 同步、API/MCP、Hugo 导出等所有特性都可用，与自托管版本一致。
- **自动 HTTPS**：默认子域名和绑定的自定义域名都会自动签发与续期证书。
- **自定义域名**：在 dashboard 中绑定你自己的域名。
- **数据库与媒体存储**：由我们配置和运维，无需关心 D1、R2、Postgres、S3 等具体实现。
- **保持在最新版本**：由 Jant 核心开发人员维护的最新版本，无需关心升级维护。

## 开始使用

1. 打开 [jant.me](https://jant.me) 注册账号
2. 创建一个站点
3. 创建之后，默认使用 jant.blog 的子域名，推荐绑定你自己的域名，进入 dashboard → 选中站点 → **域名** → 添加你的域名，按提示在域名注册商处配置 DNS 记录即可。证书会自动签发并续期。

## 不会被锁定

托管和自托管运行的是同一份开源代码，内容随时可以带走：

- **[Hugo 导出](export-and-import.md)**：把所有帖子、媒体、设置一次性导出为标准 Hugo 站点目录，可立即跑在任何 Hugo 主机上。
- **[GitHub 同步](github-sync.md)**：让站点持续把内容同步到你自己的 GitHub 仓库。仓库本身就是一个完整的 Hugo 站点，相当于你始终持有一份最新、可独立运行的副本。

任何时候都可以从托管切换到自托管，反过来也可以——通过同样的导入流程。

## 与自托管的差异

| 项目       | 托管            | 自托管                                                                    |
| ---------- | --------------- | ------------------------------------------------------------------------- |
| 配置成本   | 注册即用        | 按 [Cloudflare](deployment.md) 或 [Docker](deployment-docker.md) 文档配置 |
| 升级与运维 | 自动            | 自行执行                                                                  |
| 数据所在   | Jant 的基础设施 | 你自己的环境                                                              |
| 成本       | $10.46/年起     | 通常在 Cloudflare 免费额度内                                              |

如果你愿意花一点时间配置部署，自托管在长期成本上仍然更低，也更灵活。但如果你的优先级是"现在就开始写"，托管是更直接的路径。
