# 托管

如果你不想处理部署，[Jant](https://jant.me) 提供一个托管选项。

它和自托管在功能上是一样的——同一套代码、同一套帖子格式、同一套 dashboard、同一套 API。区别只是基础设施和账单由我们来负责。

## 价格

| 项目           | 价格      |
| -------------- | --------- |
| 一个站点       | $10.46/年 |
| 每增加一个站点 | $5/年     |
| 包含的媒体存储 | 10 GB     |
| 升级到 50 GB   | $25/年    |

`$10.46` 不是随便定的。多年前我在自己的博客里写过，我喜欢 `.com` 域名的那个价格带：低到觉得亲切，高到不是玩笑，有一种"好像占了点便宜"的感觉。后来 Cloudflare 开始按成本价提供 `.com` 注册，没有额外加价，这就自然成了 Jant 的定价锚点。

大多数人永远用不完 10 GB 媒体存储。但如果你真的需要更多，也有升级路径。

## 包含什么

- 全部 Jant 功能（threads、collections、GitHub 同步、API、Hugo 导出等）
- 自动 HTTPS
- 自定义域名
- 数据库和媒体存储由我们负责

## 不会被锁定

托管和自托管使用的是完全相同的代码。如果你以后想离开：

- 通过 [Hugo 导出](export-and-import.md) 把所有内容带走
- 或者通过 [GitHub 同步](github-sync.md)，让你的内容始终以标准 Markdown 存在于你自己的 Git 仓库里

没有专属格式，没有锁定。

## 怎么开始

打开 [jant.me](https://jant.me) 注册一个账号，建一个站点，就可以开始写。

如果有问题，可以写到 `owen#jant.me`。

## 自托管也是一等公民

如果可以的话，仍然鼓励先自托管。它并不复杂，整体结构更简单，长期成本也更低。

但有些人就是不想多处理哪怕一步部署流程。这是托管选项存在的理由。
