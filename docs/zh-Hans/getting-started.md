# 开始使用

你有三种方式得到一个 Jant 站点。

| 方式                                      | 适合谁               | 成本              |
| ----------------------------------------- | -------------------- | ----------------- |
| **[Cloudflare 自托管](deployment.md)**    | 想低维护成本长期运行 | 免费额度内通常 $0 |
| **[Docker 自托管](deployment-docker.md)** | 已经有一台服务器     | 取决于你的服务器  |
| **[Jant 托管](hosted.md)**                | 不想碰技术配置       | $10.46/年         |

三种方式跑的是同一个 Jant，随时可以 [导出](export-and-import.md) 或用 [GitHub 同步](github-sync.md) 迁走。

## 不知道选哪个

**选 [Cloudflare 自托管](deployment.md)**，如果：

- 想要免费（Cloudflare 免费额度通常完全够用）
- 愿意花 15 分钟一次性配置好
- 没有自己的服务器，有 Cloudflare 账号就行

**选 [Docker 自托管](deployment-docker.md)**，如果：

- 已经有一台自己的服务器
- 熟悉 Docker 部署

**选 [Jant 托管](hosted.md)**，如果：

- 不想处理任何技术配置
- 想现在就开始写，注册即用
- 每年 $10.46 在你的预算内

## 接下来

从 [Cloudflare 自托管](deployment.md)、[Docker 自托管](deployment-docker.md) 或 [Jant 托管](hosted.md) 中选一种托管方式继续。
