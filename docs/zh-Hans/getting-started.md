# 开始使用

你有三种方式得到一个 Jant 站点。

| 方式                                      | 适合谁                   | 成本             |
| ----------------------------------------- | ------------------------ | ---------------- |
| **[托管](hosted.md)**                     | 不想处理部署的人         | $10.46/年        |
| **[Cloudflare 自托管](deployment.md)**    | 想用极低维护成本运行的人 | 通常在免费额度内 |
| **[Docker 自托管](deployment-docker.md)** | 有自己服务器的人         | 你的服务器成本   |

三条路径得到的是同一个 Jant：同一套帖子格式、同一套 dashboard、同一套 API、同样可以随时 [导出](export-and-import.md) 或通过 [GitHub 同步](github-sync.md) 把内容带走。

## 不知道选哪个

- 想今晚就开始写：选 **托管**
- 写代码，用过 Cloudflare，想要近乎零成本：选 **Cloudflare 自托管**
- 已经有一台跑着别的服务的服务器：选 **Docker 自托管**

选错了也不要紧。Jant 不锁定数据，以后可以切换。
